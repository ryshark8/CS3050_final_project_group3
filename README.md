## Running the program

Insofar there is only one required dependency `pyarcade` which can be installed as such:
```commandline
pip[3] install arcade
```
> Note:
Some of this program relies on the built-in utility `Path` if you have a path issue
check there first

From there you can run `main.py` from an IDE or from a terminal you can run:
```commandline
python3 main.py
```
